# backgrounds/

Coloque aqui as imagens de fundo (`.png` ou `.jpg`, recomendado 1920x1080).

- `default.png` — fundo padrão
- `vanilla.png` — fundo da aba Vanilla
- `nythera.png` — fundo da aba Nythera
- outras livres — referenciáveis pelo campo `background` de qualquer manifest

O launcher lê o campo `background` do JSON da versão e busca em:
`{API_BASE_URL}/{campo_background}`
